PDF rule

The complete question is written only on the first answer-sheet page for that question. A 10-marker gets 2 pages and a 15-marker gets 4 pages. Long questions wrap automatically inside the writable area. Continuation pages contain only the supplied blank sheet. 20-mark questions remain searchable, but PDF generation is blocked for them because no 20-mark page rule was specified.
